# Research

This folder stores technical experiments and engineering evidence for the project.

**You do not need to read this folder to install or play the game.** For normal use, start with the [player guide](../docs/USER_GUIDE.md).

## What is here?

- **Reconstruction work:** investigations into original game functions and objects.
- **Compiler experiments:** tests of compiler behavior and possible code improvements.
- **Performance studies:** measurements and ideas related to speed and memory use.
- **Technical evidence:** logs, scripts, manifests, and verification results.
- **Historical experiments:** dated work kept so earlier findings are not lost.

## Where should I start?

1. Read the [project overview](../README.md).
2. Check the [roadmap](../ROADMAP.md) for planned work.
3. Open a research folder that matches the topic you need.
4. Look for its README or report before opening individual logs.

## Important

Research notes are not automatically confirmed improvements. Before treating a result as current, check which source version, tools, hardware, and test method were used.

Keep raw logs and dated experiments intact. Do not delete evidence just to make this folder look smaller. Add a short README when creating a substantial new investigation.
